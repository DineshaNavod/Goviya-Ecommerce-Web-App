# Goviya E-Commerce 🌱

Goviya is a fresh vegetable and natural products e-commerce web application developed using React + Vite. This platform connects farmers directly with customers to sell fresh, healthy, and organic products online.

## Features
- 🥦 Fresh vegetable marketplace
- 🛒 Add to cart and order system
- 👨‍🌾 Farmer product listings
- 🔍 Simple and user-friendly interface
- ⚡ Fast performance with React + Vite

## Tech Stack
- React.js
- Vite
- HTML, CSS, JavaScript

## Purpose
This project was developed as a university final project to support local farmers and promote natural, healthy food purchasing through an online platform.

## Project Name:
Goviya – Fresh & Natural Vegetable Store
